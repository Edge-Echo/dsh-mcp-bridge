      Zero-config persistent-in-session knowledge graph (entities / relations / observations). Useful for long conversations.
  playwright     ⏸ needs config
      Official Playwright MCP: navigate, click, fill, screenshot and more. First launch downloads browsers.
  remote         ⏸ needs config  (needs MCP_TOKEN)
      Template for your own or a hosted MCP server over HTTP, with optional bearer auth. Ideal for sharing one tool service across DSH / Reasonix / CodeWhale.
